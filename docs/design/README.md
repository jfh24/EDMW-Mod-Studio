# Friends dialog design references

These artifacts record the earlier Friends UX redesign included in v1.1.0:

- [ImageGen concept](online-friends-imagegen.png): the design reference used for grouping and spacing.
- [Generation prompt](online-friends-imagegen-prompt.txt): the original design brief.
- [Implemented preview](online-friends-implemented.png): a capture from that redesign's verification.

The implemented preview is historical. Later updates removed redundant headings, helper text, selection/status text, and the **Done** button. The current application closes the dialog with its title-bar **×** or **Esc** and uses tooltips/warnings for feedback. Neither these images nor the concept constitute visual acceptance of the final v1.1.0 Home sharing controls or repaint fix.
