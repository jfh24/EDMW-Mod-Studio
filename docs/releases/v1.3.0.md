# EDMW Mod Studio v1.3.0

Released 2026-10-21. This update expands custom effects and installed civilization management.

**[Download EDMW.Mod.Studio.exe](https://github.com/jfh24/EDMW-Mod-Studio/releases/download/v1.3.0/EDMW.Mod.Studio.exe)** · [GitHub release](https://github.com/jfh24/EDMW-Mod-Studio/releases/tag/v1.3.0) · [Changelog](../../CHANGELOG.md)

- Compatible civilization edits can run together, with automatic ability-command reassignment and selective uninstall.
- **Merge with…** combines installed edits under a custom name for Home management and LAN/Friends sharing. **Unmerge** restores individual entries, including on recipients.
- Custom effects support ownership transfer, unit/building transformation, spawning, instant abilities, proximity delays and recipient limits, and resource activation costs.
- Proximity sources can grant toggle abilities to several recipient types. The existing unit tooltip shows named effect descriptions and toggle states.
- Fixes cover action completion and refunds, instant-ability startup, and effective attack range.

The self-contained Windows executable requires a compatible installed game. Runtime effects remain experimental; launch them through Mod Studio. Native saves with active effects remain unsupported.

Verification covers offline native tests and disposable installation fixtures, including concurrent effects, merge/unmerge, sharing, rollback, and recovery. Live gameplay, final in-game appearance, and multiplayer synchronization remain unverified.

See the [user guide](../user-guide.md) and [development and verification](../development.md) for usage and checks.
