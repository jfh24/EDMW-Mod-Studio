# EDMW Mod Studio v1.3.0

Released 2026-10-21.

[Download EDMW.Mod.Studio.exe](https://github.com/jfh24/EDMW-Mod-Studio/releases/download/v1.3.0/EDMW.Mod.Studio.exe) · [GitHub release](https://github.com/jfh24/EDMW-Mod-Studio/releases/tag/v1.3.0) · [Changelog](../../CHANGELOG.md)

## Changes

- Added composition and selective uninstall for compatible civilization edits, with **Merge with…** and **Unmerge** actions.
- Expanded custom effects with ownership changes, transformations, spawning, resource costs, proximity controls, and group abilities.
- Improved effect activation, refunds, startup, and attack-range handling.

Runtime effects are experimental. Launch them through Mod Studio; native game saves with active effects are unsupported. See the [user guide](../user-guide.md) for current workflows.
