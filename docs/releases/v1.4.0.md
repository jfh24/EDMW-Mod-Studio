## Changes

- Added public and friends-only game rooms, friend invitations, room discovery, and EDMW host selection in Matchmaking.
- Added ICE/STUN direct gameplay with authenticated, room-scoped WSS relay fallback for UDP, TCP, and session-control traffic.
- Added persistent ICE and WSS gameplay toggles and opt-in gameplay traffic logging with endpoint metadata and no packet contents.
- Added **Prepare game network** to configure room virtual IP mappings and open the game's native multiplayer UI.
- Updated the Matchmaking panel with a right-hand room sidebar, grouped room actions, and a settings popup.
- Added gameplay transport counters and clearer network setup and connection status.
