# EDMW Mod Studio v1.4.0 Beta

**Status:** GitHub prerelease (beta) · **Date:** 2026-11-02

**[Download EDMW.Mod.Studio.exe](https://github.com/jfh24/EDMW-Mod-Studio/releases/download/v1.4.0/EDMW.Mod.Studio.exe)** · [GitHub prerelease](https://github.com/jfh24/EDMW-Mod-Studio/releases/tag/v1.4.0) · [Changelog](../../CHANGELOG.md)

This beta adds relay matchmaking and organizes the online workspace into three tabs: **Friends**, **Map collaboration**, and **Matchmaking**. Matchmaking uses the accepted online friends list for game invitations and includes public or friends-only rooms, room discovery, incoming invitations, and room controls. The section navigation and disabled actions use the same dark/gold theme, and the Friends page fills the available width while scrolling.

The supported game's TCP/IP provider can be connected to the relay through a guarded, process-local x86 bridge. The game is launched through Mod Studio; players then use the game's TCP/IP host/join screen. The relay service must be deployed from the matching 1.4.0 source for room commands and gameplay forwarding to work.

The bridge forwards limited, multicast, and local subnet-directed discovery broadcasts to all room members. In-game discovery should work even when the player hosting the game is not the player who created the Mod Studio relay room.

After **Launch EDMW**, Mod Studio restores and brings the game window to the foreground so the matchmaking dialog does not keep input. If Windows prevents activation, use **Alt+Tab** to select EDMW.

## Beta scope and compatibility

- The Windows application is self-contained and targets 64-bit Windows 10 or later. A compatible, separately installed x86 game is required for gameplay.
- The bridge checks the supported game and provider hashes before hooking. Other game builds or modified providers may not be supported.
- All players should use the same supported game/provider build and matching gameplay data.
- Live cross-internet session validation has not been completed. Internet gameplay and relay behavior should be treated as beta and may need further fixes.
- A successful relay room join confirms room membership; it does not by itself prove that the game provider connected correctly. Check the Friends status after launching the game.

See the [user guide](../user-guide.md) for setup and the [online sharing and Render setup](../online-sharing.md) for relay deployment. The previous stable release remains [v1.3.0](https://github.com/jfh24/EDMW-Mod-Studio/releases/tag/v1.3.0).
