## Changes

- Added online friends, map collaboration, and map and civilization exports through the HTTPS/WSS relay.
- Added Home actions for sharing and managing installed maps and civilization edits.
- Updated relay settings, friend requests, invitations, and the Friends dialog.

The Windows application is self-contained and requires 64-bit Windows 10 or later. A compatible game installation is required for game features. See the [user guide](../user-guide.md) for current workflows.
