# EDMW Mod Studio v1.1.0

Released 2026-10-13. This release packages every source change since v1.0.0, including the online features previously available only in source builds, the Friends redesign, the Home repaint fix, and installed-content sharing.

**[Download EDMW.Mod.Studio.exe](https://github.com/jfh24/EDMW-Mod-Studio/releases/download/v1.1.0/EDMW.Mod.Studio.exe)** · [GitHub release](https://github.com/jfh24/EDMW-Mod-Studio/releases/tag/v1.1.0) · [Full changelog](../../CHANGELOG.md)

## Share installed maps and civilization edits

Home's **Custom maps** and **Civilization edits** rows now include **LAN**, **Friends**, and **Share**. Check either destination or both and share the installed item without opening its `.edmwmap`/`.edmwciv` project. Friends selection finishes before any offers are sent; canceling it also cancels LAN delivery. A combined status dialog reports each recipient's approval, denial, or failure and cancels unfinished offers when closed.

Installed sharing does not reinstall on the sender. Maps retain their installed script and terrain payload bytes, name, and identity. When the installed x86 generator comes from an earlier build, the shared package supplies the current verified embedded generator without changing the sender's DLL. The review preview is reconstructed; the Map Designer's **Hide map preview** selection applies to Home map sharing too. Civilization shares reuse the selected installation's full portable package, including its original expected values, project, model replacements, and progression changes. Other installed edits are not folded into it. Workspace **Export over LAN** and **Export to friends** retain their existing local-install behavior.

Incomplete/orphaned maps, unsupported or damaged terrain payloads, and invalid/non-x86 generator copies cannot be shared. Valid older x86 generators are supported through the package upgrade described above. Civilization sharing requires a saved modern package whose owned data and protected original backups are intact, with no pending interrupted transaction. Earlier direct installations without that package must be restored and installed through the Civ Editor first. Recipients still validate compatibility and approve installation; an identical verified civilization package already installed is acknowledged without reinstalling.

## Online friends and collaboration

- Exchange friend codes, accept requests, and see accepted friends' online presence.
- Invite online friends into a map session with synchronized strokes, masks/resources/player starts, and named cursors. Relay order resolves overlapping confirmed edits; the desktop preserves newer pending strokes while applying acknowledgements.
- Send maps and civilization packages to selected friends without creating a collaboration session. Packages use existing validation and installation review.
- The app defaults to `https://edmw-mod-studio.onrender.com`. **Relay settings** keeps the URL editable while disconnected and preserves existing custom URLs.
- The included relay runs on Render Free without a paid disk/database. Protected desktop credentials and signed bilateral friendship approvals recover accepted contacts after the relay loses its temporary files. Cold-start connection waits are bounded and cancellable.
- Graceful socket close now informs the deployed relay and finishes cleanup before reconnect; detached sockets cannot apply stale events.

Both users need matching app builds and the same relay. LAN and online map sessions cannot be active together. Only the online map host can invite more friends. Relay restart/disconnect ends active sessions and pending offers; save editable projects locally and reconnect. Online map archives are limited to 32 MiB, civilization payloads to 128 MiB, and pending exports expire after ten minutes. See the [online guide](../online-sharing.md) for setup, recovery, and service limits.

## Friends and Home UI

The Friends dialog now groups connecting, codes, contacts/requests, and invitations, with consistent readable buttons, collapsible relay settings, and scrolling when space is constrained. Request actions identify acceptance, decline, cancellation, and removal. Unavailable invitation actions include tooltip guidance; **Leave session** appears only during a session. Redundant heading/helper/selection/footer text and the **Done** button were removed; close with **×** or **Esc**, and failures appear as warnings.

Home caches its background artwork at the current size and composes transparent descendants in a buffered panel to address the repaint glitch. Cache invalidation covers image, size, and background-color changes, with disposal on shutdown.

The new Home **LAN**/**Friends** checkboxes match the dark/gold theme, with framed boxes, visible gold checkmarks, and focus indicators. **Share** matches the size and alignment of **Details** and **Uninstall**.

The repository also includes Home/Map Designer/Civilization Editor screenshots, release download links, and [Friends design references](../design/README.md).

## Compatibility and verification scope

The executable is self-contained for 64-bit Windows 10 or later. A valid separately installed game is needed for exports and installed inventory. The native generator remains x86 for the 32-bit game. Existing project formats and legacy source identifiers remain compatible; civilization installation still checks the supported executable and native data identities. Use matching installed gameplay data for multiplayer.

The earlier online work passed 21 isolated relay tests, isolated C#/Node recovery checks through two filesystem replacements, and deployed relay checks covering 10 Node and 11 desktop check groups. Those captures predate the later text/footer simplification and Home sharing controls. Current UI appearance and in-game/multiplayer behavior remain for manual visual testing; no new visual acceptance is claimed for this release preparation. Release preparation passed the full `build.ps1` pipeline, including native resource-alignment checks, both v1.1.0 installer templates, and the self-contained desktop application. The latest editor publish completed without errors. All three .NET projects carry version 1.1.0.

Both installed-sharing suites passed.
