# Changelog

## 1.4.0 — 2026-11-09

- Added public and friends-only matchmaking rooms, invitations, room discovery, and EDMW host selection.
- Added direct ICE/STUN gameplay and authenticated, room-scoped WSS relay for UDP, TCP, and session-control traffic.
- Added persistent transport settings and optional gameplay traffic endpoint logging.
- Added **Prepare game network**, virtual IP mapping, and a temporary bridge for the game's native multiplayer UI.
- Refined the Matchmaking sidebar, room actions, discovery forwarding, and connection status.

## 1.3.0 — 2026-10-21

- Added compatible civilization edit composition, merging and unmerging, and selective uninstall.
- Expanded custom effects with ownership transfer, transformations, spawning, activation costs, proximity controls, and group abilities.
- Improved effect activation, refunds, startup, and attack-range handling.

## 1.2.1 — 2026-10-15

- Redesigned custom effect cards and added searchable multi-target selection and stat summaries.
- Added synchronized group abilities and expanded proximity effects.
- Improved native ability bindings, command placement, and legacy project support.

## 1.2.0 — 2026-10-14

- Added prototype research, proximity, and activated effects, editable unit/building attachments, per-mod controls, and game icons.

## 1.1.1 — 2026-10-14

- Added enable/disable controls for technologies, units, and buildings, plus Home context menus and installed-content sharing.

## 1.1.0 — 2026-10-13

- Added online friends, map collaboration, and map/civilization exports through an HTTPS/WSS relay.
- Added sharing and management for installed maps and civilization edits.
- Updated the Friends dialog, Home sharing controls, and relay configuration.

## 1.0.0 — 2026-10-12

- Initial release of EDMW Mod Studio with map design, civilization editing, tracked installation, and LAN collaboration/export.
